# 🏠 Home Assistant Integration

Home Genie uses `@home-assistant/mcp-server` to connect to self-hosted Home Assistant instances.

---

## Features

- 💡 **Smart Control**: Control lights, switches, climate control, and smart plugs.
- 📊 **Sensor Status**: Query temperature, humidity, power consumption, and device presence.
- ⚡ **Automations**: Trigger home scenes and automations via Telegram.
