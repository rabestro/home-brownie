# 🏛 Paperless-ngx Integration

Home Genie uses `@baruchiro/paperless-mcp` to interact with Paperless-ngx document archives.

---

## Features

- 🔍 **Natural Language Search**: Search documents by owner, date, content, or type.
- 🏷 **Automatic Metadata Tagging**: Analyze uploaded PDF documents and auto-assign correspondent, created date, and matching tags.
- 📝 **Structured Notes**: Create summary notes attached to documents.
