# 🔌 Home Connect Integration

Home Genie uses `mcp-server-home-connect` (`nikolausm/mcp-server-home-connect`) to manage smart household appliances (Bosch, Siemens, Gaggenau, Neff).

---

## Features

- 🧺 **Washing Machines & Dryers**: Query program status, remaining time, and cycle completion.
- 🍽 **Dishwashers & Ovens**: Query status, pre-heating, and power states.
